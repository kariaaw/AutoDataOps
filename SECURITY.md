# AutoDataOps Security Policy

## Project Status

AutoDataOps is under active development.
Production deployment is not yet supported.

## Vulnerability Reporting

Please do not report security vulnerabilities
through public GitHub issues.

GitHub Private Vulnerability Reporting will be
enabled after repository creation.

Until then, avoid publicly disclosing
sensitive vulnerability details.

## Security Principles

- Security by design
- Least-privilege access
- Secure credential management
- Controlled recovery operations
- Input validation
- Audit logging
- Automated security testing
- Verified incident recovery

## Production Security

Authentication, authorization, tenant isolation,
and recovery safety controls must be validated
before production deployment.
